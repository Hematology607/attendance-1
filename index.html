☁ 雲端資料庫設定（Supabase）

連接後，所有裝置的打卡資料會自動同步。只需設定一次。

📋 設定步驟：
1. 前往 supabase.com 免費註冊並建立 Project
2. 進入 Project → 左側選 SQL Editor → 貼上下方 SQL 執行
3. 到 Project Settings → API 複製 Project URL 和 anon key 填入下方
📄 點此展開 SQL（貼到 Supabase SQL Editor 執行） 
create table if not exists attendance (
  id bigint generated always as identity primary key,
  member text not null,
  month  text not null,
  rows   jsonb not null default '[]',
  updated_at timestamptz default now(),
  unique(member, month)
);
alter table attendance enable row level security;
create policy "public_rw" on attendance
  for all to anon using (true) with check (true);

create table if not exists settings (
  key   text primary key,
  value jsonb not null
);
alter table settings enable row level security;
create policy "public_rw" on settings
  for all to anon using (true) with check (true);
✅ 已儲存！
